# homebrew-par-mux

Homebrew tap for [par-mux](https://github.com/paulrobello/par-term-emu-core-rust) —
the tmux-control-mode-compatible terminal multiplexer daemon and client.

```sh
brew tap paulrobello/par-mux
brew install par-mux
```

Completions: run `par-mux completion <shell>` and follow its output.
